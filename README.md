# LABOR — Manutenção e Implantação Comercial

Site institucional estático (HTML, CSS e JS puros), sem build.

## Estrutura
```
index.html
css/style.css
js/main.js
assets/img/
```

## Rodar localmente
Abra `index.html` no navegador ou use `python3 -m http.server`.

## Publicar
GitHub Pages: Settings → Pages → branch `main`, pasta `/ (root)`.

## Antes de publicar
- Definir o domínio real (canonical, og:image absoluto, JSON-LD).
- Substituir `assets/img/hero-specialist.jpg` pela foto final do hero.
